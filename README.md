# Synthetic Data Generation

Two notebooks that teach self-learners how to generate synthetic tabular data - one from a real seed CSV using pandas, and one using scikit-learn's built-in dataset generators for regression, classification, and clustering problems.

## Learning Objectives

- Bootstrap a large synthetic dataset from a small seed CSV by sampling from observed column distributions
- Apply classification models (Gradient Boosting, Logistic Regression, Decision Trees, Random Forest) to detect donor churn
- Apply regression models (Linear Regression) to predict continuous outcomes from tabular features
- Generate synthetic benchmark datasets using `make_regression`, `make_classification`, `make_blobs`, and `make_circles`
- Understand how noise level and class separation parameters change the difficulty of a generated ML problem

## Step-by-Step Walkthrough

**Notebook 1** starts from the problem that clean, balanced real-world datasets are rarely available. Rather than looking for one, you treat a small seed CSV as an empirical distribution - each column is sampled independently to produce a larger table that preserves the rough shape of the original. The first Part implements type-aware generator functions (binary, integer, float, string) so the sampling strategy is transparent and swappable. Parts 2 and 3 then use the generated data to train real classification and regression models, showing that synthetic data is immediately useful for experimentation even before real labeled data is available.

**Notebook 2** approaches the same problem from the opposite direction: rather than building synthetic data from domain knowledge in a seed, it uses scikit-learn's `make_*` utilities to generate datasets with controlled statistical properties. This is the right tool when you want to study how an algorithm behaves as a function of noise level, class separation, or feature count - independently of any real-world messy data. Each Part visualizes the generated data before fitting a model so the learner can see what structure the algorithm is being asked to recover.

## How to Run

```bash
# Clone the repo and install dependencies
pip install -r requirements.txt

# Open notebooks in order
jupyter notebook 01_synthetic_data_generation_applied.ipynb
jupyter notebook 02_synthetic_data_generation_sklearn.ipynb
```

Run cells top to bottom in each notebook. The notebooks are independent - Notebook 2 does not depend on output from Notebook 1.

## Key Concepts Glossary

| Term | Definition |
|---|---|
| Synthetic data | Algorithmically generated data designed to resemble real data without coming from direct observation |
| Seed dataset | A small real dataset used as a statistical reference for sampling, not used directly in analysis |
| Churn rate | The fraction of a population (customers, donors, users) that stops engaging over a time period |
| Bootstrap sampling | Drawing samples with replacement from an observed distribution to produce a larger synthetic sample |
| Class separation | In a classification problem, how far apart the cluster centers of different classes are; higher separation means easier classification |
| Informative features | Features generated by sklearn's `make_regression` or `make_classification` that actually determine the target; non-informative features are noise |
| Label encoding | Converting categorical string values to integers so they can be passed to sklearn estimators |
